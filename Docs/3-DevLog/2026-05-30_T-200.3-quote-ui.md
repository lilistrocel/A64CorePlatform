#### Three new pages

| File | Lines | Description |
|------|-------|-------------|
| `QuotesPage.tsx` | ~310 | List with filter chips, search, date range, pagination |
| `QuoteFormPage.tsx` | ~530 | Create/edit form with CustomerCombobox, useFieldArray lines, live totals |
| `QuoteDetailPage.tsx` | ~490 | Detail view with contextual action bar, doc chain, attachments |

**QuotesPage** — status chips (All/Draft/Open/Closed/Cancelled), search by docNumber/customerName/bpRefNo, date range, pagination matching established pattern, "+ New Quote" button.

**QuoteFormPage** — two modes via `useParams` (`new` vs `:docId/edit`). CustomerCombobox for customer selection. useFieldArray for line management. Live totals calculation. Attachment panel shown in edit mode only. DRAFT-guard: redirects if status is not draft.

**QuoteDetailPage** — contextual action bar:
- `draft`: Edit / Post (DRAFT→OPEN) / Delete
- `open`: "Convert to Sales Order" (→ `/sales/orders-v2/from-quote/:docEntry`, T-200.4 pending) + Cancel
- `closed` / `cancelled`: read-only

"Convert to SO" button uses a hover tooltip: "Sales Order UI lands in T-200.4". The route is live in the navigate call so T-200.4 shipment automatically completes the flow.

Delete confirmation modal follows the project rule: closes via X button only, not overlay click.

**No Audit History button** — per `feedback_sales_ui_no_audit_history_button.md`. Omitted entirely.

#### `App.tsx` — 4 lazy routes added
```
/sales/quotes           → QuotesPage
/sales/quotes/new       → QuoteFormPage
/sales/quotes/:docId/edit → QuoteFormPage
/sales/quotes/:docId    → QuoteDetailPage
```
Route ordering: `/new` registered before `/:docId/edit` before `/:docId` to prevent "new" matching as docId.

#### `MainLayout.tsx`
- Sidebar entry `{ to: '/sales/quotes', icon: '📋', label: 'Quotes' }` was **already present**. No change needed.

## 8. User Verification Checklist

Navigate to `/sales/quotes` in the browser and verify:
1. Page loads showing "No Sales Quotes found" empty state with a "+ New Quote" button.
2. Click "+ New Quote" — form loads with CustomerCombobox, date fields, lines table.
3. Fill in a customer (type to search), set docDate + validUntilDate, add at least one line, submit → should create a DRAFT quote and navigate to the detail page.
4. Detail page shows quote info, "Post" and "Delete" buttons in the action bar.
5. Click "Post" → status transitions to OPEN. Action bar changes to "Convert to Sales Order" + "Cancel Quote".
6. Click "Convert to Sales Order" → navigates to `/sales/orders-v2/from-quote/:docEntry`. Expect a **404 page** — this is expected behaviour until T-200.4 ships.
7. Navigate back, click "Cancel Quote" → status transitions to CANCELLED. Page becomes read-only.
8. Sidebar "Quotes" link navigates correctly to the list.
