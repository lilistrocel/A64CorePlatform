## 3. Bugs/Issues Discovered

### Issue 1 — Finance list response shape differs from ops backend
- **Severity:** Medium (would have caused silent empty table at runtime)
- **File:** `services/finance/src/finance/utils/responses.py` → `paginated()` helper
- **Root cause:** Finance service uses `{ items, total, page, size, pages }` envelope. Ops backend uses `{ data, meta }`. The initial implementation assumed ops shape.
- **Fix:** Corrected `SaleItemFinanceExtListResponse` interface and `listSaleItemFinanceExt()` to read `response.data.items` and `response.data.total`.
- **Status:** Fixed.

### Issue 2 — Migration 019 not auto-applied (container uses pre-built image)
- **Severity:** Low (known pattern — all migrations have this characteristic)
- **Root cause:** Finance container is built from Dockerfile, not volume-mounted. New migration files need rebuild to be included in the image.
- **Workaround applied:** `docker cp` + `alembic upgrade head` inside the running container.
- **Permanent fix:** `docker compose -f docker-compose.finance.yml build finance && docker compose -f docker-compose.finance.yml up -d finance`
- **Status:** Live DB is at 019 (head). Rebuild required for persistence across container teardown.
