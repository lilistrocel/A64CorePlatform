- Added 7 API functions with `SO_BASE = '/v1/sales/orders-v2'`.

### Frontend — `frontend/user-portal/src/hooks/queries/useSalesOrders.ts` (new file)
- 7 TanStack Query hooks: `useSalesOrdersV2`, `useSalesOrderV2`, `useCreateSalesOrderV2`, `useCreateSalesOrderFromQuote`, `useUpdateSalesOrderV2`, `useDeleteSalesOrderV2`, `useTransitionSalesOrderV2`.

### Frontend — `frontend/user-portal/src/hooks/queries/index.ts`
- Added exports for all 7 SO hooks plus `soQueryKeys`.

### Frontend — `SalesOrdersV2Page.tsx` (new, ~290 lines)
- Status filter chips: All / Draft / Open / Partly Closed / Closed / Cancelled.
- Table: Order #, Doc Date, Delivery Date, Customer, BP Ref No, Total Gross, Status badge, Fulfilment pill (deliveredQty / orderedQty).
- Client-side search on docNumber / customerName / bpRefNo.
- StatusBadge styled component with `$status` transient prop; 5-color scheme.
- Pagination.

### Frontend — `SalesOrderFormPage.tsx` (new, ~450 lines)
- Three modes via URL params: `new` / `from-quote/:quoteDocEntry` / `edit/:docId`.
- From-quote mode: fetches source Quote → pre-fills all form fields, locks CustomerCombobox.
- Edit mode: fetches existing SO, pre-fills form.
- CustomerCombobox uses correct props: `valueCustomerId`, `valueCustomerName`, `onCustomerSelect`, `onClear`, `error`, `disabled`.
- React Hook Form + Zod validation with `useFieldArray` for dynamic line items.
- Live totals computed via `useMemo`.
- Credit-limit error banner: detects 409 / "credit limit" string in axios error detail.
- Attachment list shown only in edit mode (requires a docId).

### Frontend — `SalesOrderDetailPage.tsx` (new, ~500 lines)
- Fulfilment columns per line: Ordered / Delivered / Cancelled / Open (computed: `max(0, orderedQty - deliveredQty - cancelledQty)`).
- Progress bar with `$pct` transient prop: green ≥100%, amber >0%, gray 0%.
- Action bar: draft → Edit/Post/Delete; open/partly_closed → Create Delivery + Cancel (super_admin); closed/cancelled → read-only.
- Doc-chain card: baseDocRef (source Quote) + targetDocRefs (Deliveries, AR Invoices).
- Delete modal: X-only close — no overlay dismiss (project rule enforced).
- NO Audit History button.
- AttachmentList with `docType="SALES_ORDER"`.

### Frontend — `App.tsx`
- Added 3 lazy imports for `SalesOrdersV2Page`, `SalesOrderFormPage`, `SalesOrderDetailPage`.
- Added 5 routes after T-200.3 Quotes block (order: /new, /from-quote/:quoteDocEntry, /:docId/edit, /:docId before /:docId to prevent param match).
